# Modern Multi Terminal scripting examples

Copy the examples/ folder into the location you use for sample scripts in your application.
Run scripts through the application's Run Script or Multi-Script features.

## Supported TTL commands:
- variable = value
- connect
- wait
- send
- sendln
- pause
- mpause
- end

## Injected Python helpers:
- send, print
- connect_ssh, connect_serial, connect_telnet
- wait, sleep
- alert, input
- log_on, log_off
- terminal_new, terminal_close, terminal_rename, terminal_select
- select_terminal
- run_script
- terminal_name

## Note :
Replace CHANGE_ME values before using connection examples.
